# Samples

Each image is encoded at the setting with the biggest quality lead over the **best** of JPEG, WebP, AVIF and JPEG XL at the same file size. JPEG and AVIF are tried with both 4:2:0 and 4:4:4 colour; WebP with sharp YUV; JPEG XL at effort 7.

Every folder has:
- `original.png`
- the blob file `*.gsq`
- `decoded.png`: the blob file opened again
- `decoded_x4.png`: the same file drawn at 4× size
- `avif_same_size.png`: AVIF given the same number of bytes
- `comparison.png`

| Sample | Source | Blobs | Blob file | Our quality | JPEG / WebP / AVIF / JPEG XL at the same size | Result |
|---|---|---|---|---|---|---|
| [spheres](spheres/) | Glossy spheres, ray-traced by `make_samples.py` (this repo) | 3,851 | 18.5 KB (PNG 63 KB) | **51.45 dB** | 46.07 / 46.08 / 47.36 / 51.03 dB | ➖ about even: +0.42 dB at the same size, but the best needs 18.4 KB for our quality |
| [ribbons](ribbons/) | Abstract glossy colour ribbons, generated by `make_samples.py` (this repo) | 4,000 | 24.8 KB (PNG 73 KB) | **52.30 dB** | 46.12 / 44.66 / 47.55 / 49.03 dB | ✅ **+3.27 dB** over the best of them; none of them reaches our quality at any size |
| [earthrise](earthrise/) | Apollo 8 *Earthrise*, NASA photo AS08-14-2383, 24 Dec 1968 (public domain) | 7,959 | 45.0 KB (PNG 86 KB) | **48.19 dB** | 51.82 / 48.70 / 52.37 / 52.70 dB | ❌ -4.51 dB behind; the best needs only 19.6 KB for our quality |
| [doc](doc/) | Text screenshot, drawn by `make_tests.py` (this repo); boxes + symbol layer | 10,739 | 9.2 KB (PNG 17 KB) | **44.08 dB** | – / – / 42.48 / 45.85 dB | ❌ -1.77 dB behind; the best needs only 8.5 KB for our quality |

Open any `.gsq` yourself (no Python or GPU needed):
```
gsq_view.exe samples/spheres/spheres.gsq out.png --scale 4 --csv blobs.csv
```
