# Samples

Each image is encoded at the setting with the biggest quality lead over the **best** of JPEG, WebP and AVIF at the same file size. JPEG and AVIF are tried with both 4:2:0 and 4:4:4 colour; WebP with sharp YUV.

Every folder has:
- `original.png`
- the blob file `*.gsq`
- `decoded.png`: the blob file opened again
- `decoded_x4.png`: the same file drawn at 4× size
- `avif_same_size.png`: AVIF given the same number of bytes
- `comparison.png`

| Sample | Source | Blobs | Blob file | Our quality | JPEG / WebP / AVIF at the same size | Result |
|---|---|---|---|---|---|---|
| [spheres](spheres/) | Glossy spheres, ray-traced by `make_samples.py` (this repo) | 3,937 | 20.8 KB (PNG 63 KB) | **48.63 dB** | 46.79 / 46.08 / 47.36 dB | ✅ **+1.27 dB** over the best of them; the best needs 28.2 KB for our quality |
| [ribbons](ribbons/) | Abstract glossy colour ribbons, generated by `make_samples.py` (this repo) | 3,994 | 24.8 KB (PNG 73 KB) | **49.33 dB** | 46.12 / 44.66 / 47.55 dB | ✅ **+1.78 dB** over the best of them; the best needs 39.7 KB for our quality |
| [earthrise](earthrise/) | Apollo 8 *Earthrise*, NASA photo AS08-14-2383, 24 Dec 1968 (public domain) | 7,960 | 47.6 KB (PNG 86 KB) | **46.89 dB** | 51.82 / 48.70 / 52.37 dB | ❌ -5.48 dB behind; the best needs only 16.4 KB for our quality |

Open any `.gsq` yourself (no Python or GPU needed):
```
gsq_view.exe samples/spheres/spheres.gsq out.png --scale 4 --csv blobs.csv
```
